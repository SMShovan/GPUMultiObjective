Generate a connected graph and write it to a Matrix Market file.

The graph uses zero-indexed vertex IDs [0, numberOfNodes - 1] and includes multiple objective weights per edge when numberOfObjectives > 1.

Parameters
numberOfNodesNumber of vertices in the graph (must be > 0).
numberOfEdgesNumber of edges to generate (must be > numberOfNodes - 1).
directedWhether the graph is directed.
outputFileOutput filename (e.g., "data/graph.mtx").
numberOfObjectivesNumber of objectives (edge weights per edge).
objectiveStartRangeMinimum objective value (inclusive).
objectiveEndRangeMaximum objective value (inclusive).
Returns
True if the graph was generated and written successfully; false otherwise.
